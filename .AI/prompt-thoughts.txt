Task 3: File Types tab, file_types.py (new), plus browser.py, default_apps.py and README.md (edited)

It lists every known suffix with its current app. Search takes a suffix (exe, .tar.xz), a MIME type or a description, and exact suffix matches sort first.
"Only ones I changed" filters to your own overrides.

Behaviours to expect:

The File Types list builds the first time you open the tab, in batches, so startup isn't slowed.
Changing a default for something like .exe sets it for that one MIME type only. Some extensions map to two MIME names (aliases); the system resolves those itself.
Terminal, the default-terminal choice in GNOME, isn't a MIME association, so it isn't included.
